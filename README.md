## Contenu du site

- **Accueil** : présentation rapide et accès au contact et aux projets

- **Compétences** : data engineering, bases de données, architectures, cloud, data visualisation…
- **Projets** : SkillGap (job matching par similarité vectorielle), scraping & analyse de sentiment, détection de fraudes bancaires
- **Contact** : coordonnées, réseaux et formulaire de contact

## Technologies

- **HTML5 / CSS3** : site statique en une seule page, sans framework
- **JavaScript (vanilla)** : animations au défilement, barre de progression, sections projets dépliables, envoi du formulaire
- **[FormSubmit](https://formsubmit.co/)** : envoi des messages du formulaire par email, sans backend
- **GitHub Pages** : hébergement
- Polices : Space Grotesk, Inter et IBM Plex Mono (Google Fonts)

## Lancer le projet en local

```bash
git clone https://github.com/Fidelia-x/Portfolio_fidelia.git
cd Portfolio_fidelia
python -m http.server 8000
```

Puis ouvrir [http://localhost:8000](http://localhost:8000).

> ℹ️ Le formulaire de contact ne fonctionne que sur le site en ligne : FormSubmit refuse les envois depuis un fichier ouvert en local (`file://`).
